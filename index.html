About this build

Built as a single self-contained HTML file for GitHub Pages / Safari Home Screen use. Host procedures are based on the provided Corazón host sheet. Menu study cards are based on the restaurant’s official online menu as retrieved September 2026. The First Serving Test deck uses the Quizlet cards provided by the user. Reservation chits are generated locally from a pasted Resy reservation report; phone numbers and Resy table assignments are ignored.
